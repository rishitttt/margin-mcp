# Bounded product API checks

Live checks are opt-in, separate from pytest. Read keys from ignored env as data; never paste them into prompts or command arguments. A subscription/key is not a current account balance or unlimited redistribution permission. No automatic retries, fallbacks, pagination or quota resets.

## Completed pass

On27 November2026 the user approved B2/DrHTTP16/estimated credits8. The isolated pass completed with B2/DrHTTP10/estimated credits7, including connection/cleanup. It made no account probes and left the user's backend unchanged. This allocation is spent/completed; do not rerun it implicitly.

Exact client: scripts/check_product_live.py. It performs typed INFY annual readiness with same-key replay, HUL quarterly financials, local calculations on those responses, Dr metadata and INFY news/summary announcement/earnings list/detail using a returned selector. Results/sources/counters are private. It does not download attachments or collect a corpus.

## Command for a newly approved pass

```sh
.venv/bin/python scripts/check_product_live.py --confirm-live --env-file .env --output reports/private/a-new-product-live-run
```

Defaults are hard-capped B2/DrHTTP16/estimated credits8. No separate outside-ledger account calls. Output directory must be new; never overwrite a previous capture or run again to rescue a failure. A failed/held/uncertain provider stops that provider; unaffected checks may finish. Additional scope needs a new allocation.

## Interpret results

HTTP attempts, estimated credits and observed account balance are different. The live pass did not observe account charges. Zero local allowance is deliberate for local-only work; it does not mean account credits are exhausted. Metadata/schema approval is not data entitlement. Unknown units/periods/fields and incomplete component results remain explicit.

Citation/source imports use retained returned text, not attachment contents. Provider filters can include other issuers; host relevance is mandatory. Local calculations over one captured response are not extra fresh wrapper executions or independently verified facts. Preserve source basis/period/units and declared assumptions.
