# Product context

Margin is a provider-backed Indian financial research interface. The four-person project aims at a usable product. main delivers aggregation; former corpus/PDF code stays on d1. No persistent market repository is required.

## Architecture

Core services handle reviewed schemas, provider admission, bounded transient data/keys, receipts, financial normalization and local calculations. Adapters are stdio MCP, optional Unix shared backend, CLI/skill and a temporary FastAPI/static workbench. B uses REST; Dr uses the guarded upstream MCP session. all39 is supported; narrower profiles are optional projections of the same owner.

No Margin LLM/browser/forecast generator. Financial facts retain units, dates, basis, scope, unknowns and provenance. Review protocols validate supplied references/quotes and aggregate host judgments; they do not authenticate originals or establish market sentiment.
